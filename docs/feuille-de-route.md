# Feuille de route

## Fait

- [x] Retrouver automatiquement le DPE officiel à partir d'une annonce réelle
- [x] Recalcul des DPE récents avec la méthode 3CL (écart de 1 à 2 %)
- [x] Simulation des gestes de travaux et règle « pire des classes énergie / CO₂ »
- [x] Étiquette 2027 avec le nouveau coefficient électrique
- [x] Chiffrage par corps de métier sur grille simulée, facture et temps de retour
- [x] Trois parcours (Express, Équilibre, Grand saut) et alertes contextuelles
- [x] Maquette mobile sur 5 logements réels ([démo](../demo/))

## Prochaines étapes

1. **Accès aux données** : fiabiliser le téléchargement du détail des DPE depuis un
   hébergement français.
2. **Prototype en ligne** protégé par mot de passe : coller un lien, obtenir l'écran
   de résultat.
3. **Mode agent en priorité** : plus simple, données exactes, aucune extraction
   d'annonce.
4. **Grille de prix réelle** construite avec des artisans locaux, pour l'énergie et
   pour l'esthétique.
5. **Bloc esthétique** : finitions chiffrées à part et visuels « après » générés, avec
   filigrane.
6. **Validation juridique** : données personnelles, extraction d'annonces, licence du
   moteur, visuels générés par IA.
7. **DPE de première génération** : modèle simplifié avec indicateur de fiabilité.
